# cadeia-de-valor-da-IA
Este painel usa patentes como lente para mapear a cadeia de valor da inteligência artificial, da fábrica ao produto final.  Cada patente é classificada em cinco camadas: Infra Física, Chips &amp; Hardware, Cloud &amp; Compute, Modelos de IA e Software &amp; Aplicação. Uma mesma patente pode tocar mais de uma camada, o que chamamos de convergência.
**Painel online:** https://cadeia-ia.streamlit.app/
**Como citar:** use o botão *Cite this repository* (à direita) ou veja o arquivo `CITATION.cff`.
